# River Rush 3D

Projet réalisé par **Yassin Es Saim** — **Master MIAGE IA2, Université Côte d’Azur**.

River Rush 3D est un jeu web 3D inspiré de l’esprit Wii/Kinect, développé avec Babylon.js, TypeScript, MediaPipe et des steering behaviours.

Le projet principal se trouve dans le dossier :

```text
riverush/
```

## Lancer en local

```bash
cd riverush
npm install
npm start
```
